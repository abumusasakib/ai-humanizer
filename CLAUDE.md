# ai-humanizer project instructions

Use this project when you need to rewrite text so it sounds more natural, direct, and human.

## What this project is for

- remove AI-style phrasing
- simplify dense or repetitive writing
- make a draft sound less robotic
- preserve meaning while improving readability

## What to do

1. Read the text for meaning and audience first.
2. Check it against the AI-writing patterns in `references/ai_writing_patterns_35.md`.
3. Rewrite the text in a clearer, more natural voice.
4. Keep names, numbers, dates, quotes, and citations unchanged unless the source itself changes them.
5. Do a final pass for anything that still sounds templated.

## Style rules

- Prefer simple words over flashy ones.
- Avoid filler like `leverage`, `harness`, `robust`, and `comprehensive`.
- Avoid stock phrases like `in conclusion` or `at the end of the day`.
- Avoid em dashes unless the source already uses them.
- Keep the writing crisp and uneven in a natural way.
- Use contractions when the tone allows it.

## Tone

- Business: direct, calm, and specific.
- Academic: formal, but not stiff.
- Casual: conversational and lightly personal.
- Creative: focus on rhythm and voice, but still avoid clichés.

## Important limits

- Leave code, data, and frontmatter alone.
- Do not add new facts or claims.
- Do not change citations unless the source text changes.

## Reference files

- `references/ai_humanizer_knowledge.md`
- `references/ai_writing_patterns_35.md`

## Good shorthand

If you want this project to be effective, keep the job simple:

- preserve the message
- clean up the wording
- keep the voice human
